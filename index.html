/02 AI agent · fully local

Job Radar — my personal job-matching agent

An agent that hunts, verifies and ranks job postings for me every morning.

I built an autonomous agent with local tooling: it searches Dutch job boards daily, checks each posting is actually still live (many mirrors show dead jobs), scores every candidate against my profile with a local LLM running on my own machine, and delivers a ranked top-10 to my phone with links and salary notes. My profile, scores and reasoning never leave the house.
