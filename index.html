/01 AI · local LLM

Vendor Relationship Analyzer

Messy Excel in, sendable analysis out.

A company file held dozens of costs and business partner relations in a format nobody could act on. I built a Python script that reads the messy Excel, enriches each row through web scraping, and uses a free Mistral LLM running locally (Ollama) to describe every row and classify it into cost categories: construction, telecom, IT and the like. The result: one vendor analysis document the team could send out as-is.

inputmessy export.xlsx
B0412 · "roof repair + scaffolding, winter" · 2019? · "factuur in het Nederlands"
B0577 · "mobile data contract ×34" · €4,910 · jaar onbekend
B1003 · "hosting + license renewal" · 2021 · "auto-renew?"
dozens of rows like this · free text · half Dutch half English
outputanalysis document
CONSTRUCTION roof repair + scaffolding → construction costs · supplier verified via web
TELECOM mobile data contract ×34 → telecom costs · contract period normalized
IT hosting + license renewal → IT costs · flagged as recurring spend
✓ 1 described + classified row per row · every row gets a cost category
PythonOllama + Mistral (local) web scrapingExcel → classified report
outcome: every row described and classified into a cost category, ready to send
